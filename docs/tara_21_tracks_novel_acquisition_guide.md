### 2. 自动化落库与配额流水线
当您采购并下载完某一个赛道的一批 `.epub`（例如放入 `lora/` 根目录）后：
```bash
# 启动该批次全部小说的全自动入库处理流水线（6~8线程并发）
for book in *.epub; do
    .venv/bin/python3 -u src/process_single_novel.py "$book" --ratio 0.1 --threads 8
done
```
- **自动切片**：每本自动抽取 10% 核心章节；
- **自动对齐**：每章自动盲写初稿并生成 DPO 偏好对；
- **自动穿透**：SFT 样本默认固化【总纲 + 事实基座 + 前置真实剧情穿透 + 起止铁锚】；
- **自动归档**：处理完毕后该书自动移入 `processed_books/`，`config/tracks.json` 自动更新该赛道存量！
